## ⚙️ Physics Integration

### Scenarios Configured
All 5 levels have complete physics scenarios ready to use:
- Level 1: Ball rolling down ramp
- Level 2: Two balls colliding
- Level 3: Energy transfer on ramp
- Level 4: Multiple forces demonstration
- Level 5: Complex multi-entity scenario

### How to Use
```cpp
// Get entities for current level
auto entities = gameEngine.getScenarioEntities(levelId);

// Add to physics engine
for (auto& entity : entities) {
    physicsEngine.addEntity(entity);
}
```
