# 10. TROUBLESHOOTING
# ============================================================================

# C++ Build Errors:
#   - "SDL.h not found": Install libsdl2-dev
#   - "TTF_OpenFont failed": Install fonts-dejavu
#   - Linker errors: Ensure pkg-config is installed

# Python Backend Errors:
#   - "Module not found": pip install <module>
#   - "API key not found": Check .env file exists
#   - CORS errors: Install flask-cors

# Connection Errors:
#   - Frontend can't reach backend: Ensure backend is running on port 5000/8000
#   - Check firewall settings
#   - Verify URL in GameEngine::processWithAI() method
